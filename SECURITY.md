# Security policy

`worktree-ports` runs your commands, sets their environment, and writes claim files to a per-user state directory, so
security reports are welcome.

## Reporting a vulnerability

Please report it privately through GitHub's
[private vulnerability reporting](https://github.com/jimbeveridge/worktree-ports/security/advisories/new), not in a
public issue. Include the version, your platform, and steps to reproduce. You can expect a reply within a week.

## Supported versions

Only the latest release receives fixes.
